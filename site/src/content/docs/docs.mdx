Knocker is a loadable SQLite extension plus language bindings. Durable webhook semantics live in Rust and SQLite, while each binding adapts its host language to the same stored contract.

If you're new, read [Getting started](/getting-started/). If you're wiring Knocker into an existing web app, start with [Framework integration](/guides/framework-integration/). Otherwise, pick the job you need:

## What's not here

Framework adapters for FastAPI, Flask, Django, Rails, Express, and friends are not shipped. Wiring Knocker into a web framework is route glue: read the raw body, pass headers/query to `receive(...)`, return `result.status_code`.

Out of scope on purpose: hosted relays, operator API servers, HTML control planes, generic queue APIs, and exactly-once side effects.
