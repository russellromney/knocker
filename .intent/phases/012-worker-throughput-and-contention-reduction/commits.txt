Phase 012 verification and evidence

What changed
- production worker claim batching landed with a fixed internal batch size of `10`
- `run_worker(stop_event=...)` now drains already-claimed local buffered jobs before exit instead of stranding them until lease expiry
- user-facing docs now recommend one long-lived `knocker.open(...)` per process for hot paths and describe many same-file opens as a degraded contention mode

Direct proof
- `uv run --group dev pytest tests/test_ingest_worker.py -k "uses_batched_claims or stop_drains_locally_buffered_claims_before_exit or multiple_workers_process_each_event_once or idle_worker_wakes_on_wal_commit_without_waiting_for_poll_timeout"`
  - `4 passed`
- `uv run --group dev pytest tests/test_performance_floors.py`
  - `3 passed`
  - includes the bounded contention-sensitive proof: `1 producer / 2 workers`

Refreshed local benchmark evidence

  - `experiment_serialization_cost`
    - JSON encode/decode remains on the order of `~1-2 us/op`, confirming it is still not the main bottleneck
