---
title: SQLite bindings
description: Node, Bun, Ruby, Go, and Elixir bindings over Knocker's shared SQLite contract.
---

Knocker is a loadable SQLite extension plus language bindings. The bindings
on this page talk to the same shared SQLite contract as the Python package.

Every binding in this page proves the same shared SQLite-contract baseline:

- open/bootstrap
- endpoint registration
- trusted ingest
- provider-verified `receive(...)` for curated providers through the shared SQLite extension
- endpoint and event-type-specific handler registration, with endpoint fallback
- one-shot and long-running worker-processing paths
- handler access to the same SQLite transaction used for Knocker's event transition and queue acknowledgement
- handler-failure rollback before retry/dead-letter bookkeeping
- `get_event`
- `list_events`
- delivery reads
- `replay`
- `requeue`
- `ignore`
- `replay_delivery`
- retention pass/loop helpers
- prune/audit reads

These bindings load the Knocker SQLite extension directly. They do not wrap
separate Honker language packages; queue operations go through the shared
SQLite functions exposed by the extension. They are not framework adapters.

## Node

Source: `packages/knocker-node`

```js
import { KnockerSqlite } from "./packages/knocker-node/index.mjs";

const db = new KnockerSqlite("app.db");
db.addEndpoint({
  name: "github",
  path: "/webhooks/github",
  provider: "github",
  secrets: ["github-secret"],
});

const result = db.receive({
  endpoint: "github",
  body: Buffer.from('{"zen":"keep it logically awesome"}'),
  headers: {
    "X-Hub-Signature-256": "sha256=...",
    "X-GitHub-Delivery": "delivery-1",
    "X-GitHub-Event": "push",
  },
});

db.registerHandler("github", (event, tx) => {
  // Assume this app-owned table already exists.
  tx.prepare("INSERT INTO handled_events (event_id) VALUES (?)").run(event.id);
  console.log("handled", event.id);
});

await db.runWorker({ workerId: "node-worker", maxJobs: 1 });
db.replay(result.event_id);
db.ignore(result.event_id);
```

## Ruby

Source: `packages/knocker-ruby`

```ruby
require_relative "../packages/knocker-ruby/lib/knocker_sqlite"

db = KnockerSqlite::Database.open("app.db")
db.add_endpoint(
  name: "github",
  path: "/webhooks/github",
  provider: "github",
  enabled: true,
  secrets: ["github-secret"],
)

result = db.receive(
  endpoint: "github",
  body: "{\"zen\":\"keep it logically awesome\"}",
  headers: {
    "X-Hub-Signature-256" => "sha256=...",
    "X-GitHub-Delivery" => "delivery-1",
    "X-GitHub-Event" => "push",
  },
)

db.register_handler("github") do |event, tx|
  # Assume this app-owned table already exists.
  tx.exec("INSERT INTO handled_events (event_id) VALUES (#{event['id']})")
  puts "handled #{event['id']}"
end

db.run_worker(worker_id: "ruby-worker", max_jobs: 1)
db.replay(result["event_id"])
db.ignore(result["event_id"])
```

## Go

Source: `packages/knocker-go`

```go
webhooks, err := knockersqlite.Open("app.db")
if err != nil {
    panic(err)
}
defer webhooks.Close()

provider := "github"
_, err = webhooks.AddEndpoint(knockersqlite.AddEndpointParams{
    Name:     "github",
    Path:     "/webhooks/github",
    Provider: &provider,
    Enabled:  true,
    Secrets:  []string{"github-secret"},
})

webhooks.RegisterHandler("github", func(event knockersqlite.Event, tx *knockersqlite.Tx) error {
    // Assume this app-owned table already exists.
    _, err := tx.Exec("INSERT INTO handled_events (event_id) VALUES (?)", event.ID)
    if err != nil {
        return err
    }
    return nil
})

result, err := webhooks.Receive(knockersqlite.ReceiveParams{
    Endpoint: "github",
    Body:     []byte(`{"zen":"keep it logically awesome"}`),
    Headers: map[string]any{
        "X-Hub-Signature-256": "sha256=...",
        "X-GitHub-Delivery":   "delivery-1",
        "X-GitHub-Event":      "push",
    },
})

_, err = webhooks.RunWorker(context.Background(), "go-worker", 1)
_ = webhooks.Replay(*result.EventID)
_ = webhooks.Ignore(*result.EventID)
```

## Elixir

Source: `packages/knocker-elixir`

```elixir
{:ok, opened} = KnockerSqlite.open("app.db")

webhooks =
  KnockerSqlite.register_handler(opened, "github", fn event, tx ->
    # Assume this app-owned table already exists.
    :ok = KnockerSqlite.Tx.exec(tx, "INSERT INTO handled_events (event_id) VALUES (#{event["id"]})")
    IO.inspect(event["id"], label: "handled")
  end)

{:ok, _endpoint_id} =
  KnockerSqlite.add_endpoint(webhooks, %{
    name: "github",
    path: "/webhooks/github",
    provider: "github",
    enabled: true
  })

{:ok, result} =
  KnockerSqlite.receive(webhooks, %{
    endpoint: "github",
    provider: "github",
    secrets: ["github-secret"],
    body: ~s({"zen":"keep it logically awesome"}),
    headers: %{
      "X-Hub-Signature-256" => "sha256=...",
      "X-GitHub-Delivery" => "delivery-1",
      "X-GitHub-Event" => "push"
    }
  })

1 = KnockerSqlite.run_worker(webhooks, "elixir-worker", %{max_jobs: 1})
{:ok, _} = KnockerSqlite.replay(webhooks, result["event_id"])
{:ok, :ignored} = KnockerSqlite.ignore(webhooks, result["event_id"])
```
